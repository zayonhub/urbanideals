# Urban Ideals: standalone HTML website

Nine HTML pages, all nine image/logo/icon assets, CSS and JavaScript. No npm, React, server or build step required.

## Upload to GitHub

1. Extract the ZIP.
2. Upload the CONTENTS of Urban-Ideals-HTML to the root of your GitHub repository. Keep assets/ and images/ intact.
3. For GitHub Pages, select your repository branch and root folder in Settings > Pages.
4. Open the URL GitHub provides. Relative links support repository subpaths as well as custom domains.

Open index.html to preview locally. Keep all files together; uploading only index.html will omit styles and images.

## Included behavior

- Home navigation and responsive mobile menu
- Let's talk links directly to https://wa.me/2349055554617
- Each service enquiry link preselects the service on the contact page
- Form validates required fields and opens WhatsApp with the message prepared; visitor presses Send in WhatsApp
- Scroll animations respect reduced-motion preferences
- All photography, logo and favicon stored in images/

Fonts use Google Fonts online with local fallback fonts when offline. The photos are illustrative architectural imagery, not a claimed project portfolio.

Edit the HTML for content; assets/style.css for styling; assets/site.js for interactions. This export does not automatically sync with the hosted Sites version.
